# 数据复盘流程：一个人也能做

## 1. 从哪里拿数据
- X：打开自己帖子的分析页面，记录展示/浏览、点赞、评论、转发、收藏；是否可导出CSV以账号权限和当前界面为准，不能保证所有账号都能导出收藏/留存。
- YouTube Studio：内容/Analytics里查看你拥有的视频的Views、Watch time、Retention等，支持的指标以视频类型和分析页面为准；导出后需按模板重命名。
- TikTok：创作者后台/Analytics查看具体视频的观看、点赞、评论、分享、完播/平均观看时长等（实际能看哪列以账号和地区为准）。
- Excel/表格里把各平台列整理成 `examples/blank-template.csv`；不提供的数据保持单元格空白，不能填0凑数。

## 2. 打开Excel填数据
第一行列名不要改。1行=1条作品。`views`需要填写整数。留存率允许输入 `62%` 或 `0.62`。

## 3. 一键复盘
双击 `启动数据复盘.bat`，选2，粘贴CSV路径。生成的报告在项目文件夹 `reports`（相同目录旧报告会被覆盖，请另存重要报告）。

## 4. Grok Bot怎么结合用
把 `reports/report.md` 和 `reports/action_plan.json` 发给Bot，说：“请根据这些**真实数据**，给我下周3个具体选题，分别提供一个前三秒开头和一个待验证的假设，所有建议附依据，不要虚构指标。”

## 5. 怎样判断靠不靠谱
同平台至少3条才试着找规律，某类选题至少2条才能比较中位数。播放太少的作品可先排除；本工具默认100播放量门槛，改用 `--min-views 500` 可以提高要求。

所有这些是描述性比较，不是科学显著性证明。不同平台的浏览/曝光不可直接相加当总成绩。
